name: Seta-design-system
description: "Astryx-based work surface. Built on Meta's Astryx design system
  (@astryxdesign/core + a custom `seta` theme), extending the `neutral` base
  theme with Seta's brand accent. Warm off-white light surfaces by default
  (Astryx `neutralStyle: warm`), dark mode retained for inverse contexts. The
  single chromatic accent is Seta blue #0047FF — verified against the live
  seta-international.com brand — applied via Astryx's `color.accent` token
  input, which derives the full accent/on-accent/border/icon/text palette.
  Display + body type run Geist (Geist Mono for code), configured via
  Astryx's `typography.body/heading/code` theme fields. Radius uses Astryx's
  `radius.base: 4` scale (inner/element/container/page/chat)."

implementation_notice: |
  The authoritative theme source is
  `packages/shared-ui/src/theme/astryx-seta.theme.ts` (a `defineTheme` config).
  Compiled output (`astryx-seta-theme.css` + `seta.js`/`seta.d.ts`/
  `seta.variants.d.ts`) lives in `packages/shared-ui/src/styles/`, generated by
  `pnpm --filter @seta/shared-ui theme:build` — never hand-edit the generated
  files. Where this document and `astryx-seta.theme.ts` disagree, the theme
  source wins.

  As of FUT-562's foundation change, this theme's CSS loads only in
  Storybook (`packages/shared-ui/.storybook/preview.css`) — `apps/web` does
  not load any Astryx CSS yet. `@astryxdesign/core`'s vendor base stylesheet
  ships unscoped `:root` token defaults that collide with Seta's own
  same-named tokens in `tokens.css`; loading it into the shared app CSS root
  requires `<Theme>` mounted at the true app root (so Astryx's `@scope`d
  overrides reach `<html>`) to resolve safely, which is scoped to the
  primitive-migration follow-on plan, not this one.

  Seta's pre-Astryx custom tokens (priority palette, group-theme colors,
  kanban-specific values) still live in `packages/shared-ui/src/styles/tokens.css`
  unchanged until the components that consume them are migrated onto Astryx
  primitives — see the migration plans referenced from FUT-562.

theme:

  accent: "#0047FF"
  neutralStyle: warm
